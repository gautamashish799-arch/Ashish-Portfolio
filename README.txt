GITHUB UPLOAD INSTRUCTIONS

1. Open your Ashish-Portfolio GitHub repository.
2. Click Add file > Upload files.
3. Drag index.html AND the entire images folder into the upload area.
4. Commit changes.
5. In Settings > Pages, choose Deploy from a branch > main > /(root) and Save.

NOTE: If GitHub does not accept a folder through the file chooser, drag the images folder from Windows File Explorer onto the upload page.
